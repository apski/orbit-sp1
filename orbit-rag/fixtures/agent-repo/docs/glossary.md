# Glossary

- **Spot**: a named surf or tide location with coordinates and a forecast model.
- **Alert**: a user rule that notifies when a spot's forecast matches conditions.
- **Session log**: a record of a surf session at a spot, with optional photos.
- **Forecast model**: the upstream numerical model a spot uses (global or regional).
- **Sync queue**: the local, persisted list of mutations waiting to upload.
- **Coordinator**: native object that owns a navigation stack for one tab.
- **ScreenHost**: the native view that mounts a React Native screen for a route.
- **Runtime**: the native binary fingerprint an OTA update targets.

- **Analytics vendor**: PostHog, EU cloud; the SDK starts only after consent.

- **Base locale**: `en-US`, the locale every translation falls back to when a key is missing.
